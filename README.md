# nronga-bot.github.io

Developer website for the MjasiDeni Android app, served at `https://nronga-bot.github.io/`.

- `index.html`: developer landing page, linking to the MjasiDeni legal site at `https://nronga-bot.github.io/mjasideni-legal/` (a separate repository, `mjasideni-legal`).
- `app-ads.txt`: authorized ad sellers file for AdMob (IAB Tech Lab app-ads.txt), served at `https://nronga-bot.github.io/app-ads.txt`.

Plain HTML and CSS, with no scripts, cookies or analytics.

Do not create a folder named `mjasideni-legal` in this repository: that path belongs to the project site.
